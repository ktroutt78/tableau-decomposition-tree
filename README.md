# tableau-decomposition-tree

Repository for the **Decomposition Tree V2** Tableau extension and related projects.

## Decomposition Tree V2 (Tableau Extension)

Interactive hierarchical decomposition tree built with Svelte and D3. Drop a measure and dimensions, then drill down to explore what's driving your numbers.

- **Extension docs:** [decomp_tree_v2/README.md](decomp_tree_v2/README.md)
- **Live extension (index):** `https://ktroutt78.github.io/tableau-decomposition-tree/decomp_tree_v2/docs/index.html`
- **Manifest (.trex):** `https://ktroutt78.github.io/tableau-decomposition-tree/decomp_tree_v2/docs/DecompositionTreeV2.trex`

### Tableau Cloud / Server

When configuring the extension in Tableau Cloud (or Tableau Server), use:

- **Extension URL / Index URL:**  
  `https://ktroutt78.github.io/tableau-decomposition-tree/decomp_tree_v2/docs/index.html`

Your administrator may need to allowlist `ktroutt78.github.io` in extension settings.
